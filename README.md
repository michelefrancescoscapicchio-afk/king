# Kingdom Life Max PWA

Fertiges PWA-Projekt für iPhone-Homescreen-Installation.

## Lokal starten
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Auf iPhone installieren
1. Projekt online stellen (Vercel, Netlify oder GitHub Pages).
2. Link in Safari öffnen.
3. Teilen → Zum Home-Bildschirm.
4. App wie normale App starten.

## Enthalten
- iPhone-Hochformat-UI
- PWA Manifest
- LocalStorage Save/Load
- Lebenssimulation
- NPCs, Fraktionen, Weltkarte, Börse
- Karriere, Mafia, Krieg, Politik, Besitz, Gesundheit
